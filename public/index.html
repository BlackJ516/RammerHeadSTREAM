Only you know it: the server keeps a one-way hash and this browser keeps a sign-in token, never your password.

This server needs an invite code to create an account. Enter the code the administrator gave you. If you are the administrator and this is a new install, the first code is printed in the server console.

          Account & password

          Your password belongs to you alone. Change it here at any time.

          At least 8 characters. Any characters work: letters, numbers, spaces, symbols, emoji.

          Delete my account

          This permanently deletes your account and your browsing session on the server, and removes your bookmarks and history from this browser. It cannot be undone. A forgotten password cannot be recovered, so this is also how to start over.
