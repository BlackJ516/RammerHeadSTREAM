Quick answers about using {{site.name}}. To report abuse, use the report page.

Getting started

How do I begin?

Open the main page, choose Create account, pick a username and a password, then type a web address or a search into the address bar and press Go. The page opens in a new browser tab.

What can my username and password contain?

Anything: letters, numbers, spaces, symbols, emoji, in any language. A username needs 3 to 32 characters and a password at least 8. Capital letters in a username are ignored, so Sam and sam are the same account. A few very common passwords are not accepted.

Why can't I create an account?

The message tells you which box to fix. The usual reasons are a password that is too short, two password boxes that do not match, a username that is already taken, or, on some servers, a missing invite code. Servers that need an invite code say so on the sign-up screen.

I forgot my password.

Passwords cannot be recovered. The server never stores your password, only a one-way hash of it, so nobody, including whoever runs this site, can read it or reset it for you. If you forget it, create a new account. Your bookmarks and history stay in your browser under the old username.

Tabs, bookmarks and history

How do tabs work?

Every address opens in its own browser tab, and the main page keeps a list of them with back, forward, reload and close buttons. If your browser blocks pop-ups, the page opens in the current tab instead; allow pop-ups for this site to use tabs. The list is kept while the main page stays open.

Where are my bookmarks and history?

In your own browser, saved per account. They do not follow you to another browser or device, and clearing your browser's site data removes them. They are never sent to the server.

What does "Start a fresh browsing session" do?

Cookies and site data from the websites you visit are kept in a browsing session on the server. This button deletes that session, so the sites no longer recognise you. Idle sessions are also removed automatically after a few days.

When a page does not work

A website looks broken or will not load.

Some websites, especially complex web apps and video players, depend on features a proxy cannot always reproduce. Try reloading, then Start a fresh browsing session in Settings. If Settings lists more than one transport, try another one.

What are transports?

A transport is the method used to carry requests to the web. The built-in HTTP method is always the starting point. If the installed engine supports others, such as libcurl or Epoxy, they appear in Settings → Connection. You can name a fallback, and the page will switch to it if the first one fails its check. A transport only appears when the engine supports it.

Why was an address refused?

For safety the service refuses addresses on private or internal networks, local files, and ports used by mail servers and databases. Ordinary public websites are not affected.

Safety

Is it safe to sign in to other websites here?

The sites you use through any proxy are visible to the proxy's operator. Only enter passwords for important accounts if you trust the operator, and read the privacy policy first.
